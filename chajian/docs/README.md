## 🏗️ 技术架构概述

### 系统组成
```
┌─────────────────────────────────────────────────────────┐
│                   一念职达助手系统架构                      │
├─────────────────────────────────────────────────────────┤
│  浏览器扩展层                                              │

│  └── 文件服务 (File Service)                              │
└─────────────────────────────────────────────────────────┘
```

### 核心技术栈
- **前端**：Chrome Extension Manifest V3, Vanilla JavaScript, CSS3
- **后端**：Node.js, Express.js, JWT认证
- **AI引擎**：机器学习模型，自然语言处理
- **数据库**：关系型数据库（用户数据）+ 缓存（Redis）

## 🎯 核心功能特性

### 1. AI智能填表
- **两阶段分析**：页面结构分析 + 智能填写策略
- **多框架支持**：React、Vue、Angular等现代前端框架
- **动态适配**：自动处理懒加载和动态内容

### 2. 认证系统
- **多重登录**：邮箱登录 + 微信OAuth
- **双令牌机制**：Access Token (15分钟) + Refresh Token (14天)
- **自动刷新**：无感知令牌续期

### 3. 悬浮助手
- **智能对话**：自然语言交互和指令识别
- **实时反馈**：填写进度和状态提示
- **个性化配置**：可自定义显示和功能设置

### 4. 简历管理
- **多格式解析**：PDF、Word文档智能解析
- **结构化存储**：标准化简历数据模型
- **智能匹配**：简历字段与表单字段的智能映射

## 🚀 开发和部署

### 开发环境设置
```bash
# 1. 克隆项目
git clone <repository-url>

# 2. 安装依赖
npm install

# 3. 配置环境
cp config/development.json.example config/development.json

# 4. 启动开发服务
npm run dev
```

### 扩展安装
1. 打开Chrome浏览器，访问 `chrome://extensions/`
2. 开启"开发者模式"
3. 点击"加载已解压的扩展程序"
4. 选择项目根目录
5. 确认安装完成

### API部署
```bash
# 1. 构建项目
npm run build

# 2. 部署到服务器
npm run deploy:production

# 3. 启动服务
npm run start:production
```
