## 🎯 产品定位

### 产品使命
为求职者提供AI驱动的智能求职助手，通过自动化技术简化求职流程，提升求职成功率。

### 目标用户
- **在校学生**：应届毕业生、实习生
- **职场人士**：寻求跳槽的在职人员
- **求职活跃用户**：频繁投递简历的求职者
- **时间敏感用户**：希望快速完成申请流程的用户

### 核心价值主张
- **效率提升**：自动填写表单，节省90%重复劳动
- **智能匹配**：AI分析表单结构，精准映射简历信息
- **一键应用**：支持主流招聘网站和企业官网
- **体验优化**：简洁界面，操作简单，学习成本低

## 🚀 核心功能

### 1. AI智能表单填写

#### 功能描述
基于先进的AI技术，自动识别网页表单结构，智能填写求职申请表单。

#### 核心特点
- **两阶段AI分析**
  - 第一阶段：页面结构分析和表单字段识别
  - 第二阶段：基于用户简历数据生成填写方案
- **智能字段映射**
  - 支持200+常见表单字段类型
  - 智能识别字段语义（姓名、电话、邮箱等）
  - 支持中英文字段标签识别
- **多框架适配**
  - React、Vue、Angular等现代前端框架
  - jQuery、Bootstrap等传统框架
  - 原生HTML表单
- **动态表单处理**
  - 自动展开折叠区域
  - 处理懒加载内容
  - 适配单页应用(SPA)路由变化

#### 技术实现
```javascript
// 表单分析API调用示例
const analysisResult = await aiService.analyzePage({
  html: simplifiedPageHTML,
  url: currentPageURL,
  companyName: "目标公司",
  positionName: "目标职位"
});

// 智能填写API调用示例
const fillResult = await aiService.fillValues({
  sessionId: analysisResult.sessionId,
  resumeId: userResumeId,
  customData: { expectedSalary: "15-25K" }
});
```

#### 支持的表单类型
- **基本信息表单**：姓名、性别、年龄、联系方式
- **教育背景表单**：学校、专业、学历、毕业时间
- **工作经历表单**：公司、职位、工作描述、在职时间
- **技能特长表单**：专业技能、语言能力、证书资质
- **求职意向表单**：期望职位、期望薪资、工作地点

### 2. 智能对话助手

#### 功能描述
页面内嵌式AI对话助手，支持语音指令控制和实时状态反馈。

#### 核心特点
- **悬浮式交互界面**
  - 页面右下角智能悬浮按钮
  - 可展开的对话窗口
  - 支持拖拽和位置调整
- **自然语言交互**
  - 支持语音指令：「开始填写」「暂停」「继续」
  - 智能意图识别和响应
  - 多轮对话支持
- **实时状态反馈**
  - 填写进度实时显示
  - 错误提示和建议
  - 成功率统计

#### 交互流程
```
用户输入 → 意图识别 → 执行动作 → 状态反馈
   ↓           ↓           ↓          ↓
"开始填写" → 启动填表 → 扫描表单 → "正在分析页面..."
"暂停"    → 暂停操作 → 保存状态 → "已暂停，输入'继续'恢复"
"继续"    → 恢复操作 → 继续填写 → "继续填写中..."
```

#### 支持的指令类型
- **操作指令**：开始、暂停、继续、停止、重新开始
- **查询指令**：进度查询、状态查询、帮助说明
- **配置指令**：设置期望薪资、修改工作地点

### 3. 多重身份认证

#### 功能描述
支持多种登录方式，保障用户账户安全，提供个性化服务。

#### 认证方式

##### 3.1 邮箱/用户名登录
- **注册流程**
  ```
  输入信息 → 邮箱验证 → 密码设置 → 账号创建成功
  ```
- **登录流程**
  ```
  输入凭据 → 身份验证 → 获取Token → 登录成功
  ```
- **安全特性**
  - 密码强度检测
  - 账号锁定机制
  - 异地登录提醒

##### 3.2 微信OAuth登录
- **授权流程**
  ```
  点击微信登录 → 打开二维码页面 → 微信扫码 → 授权确认 → 登录成功
  ```
- **技术实现**
  ```javascript
  // 微信OAuth登录流程
  const authURL = `${CONFIG.API_BASE_URL}/api/auth/wechat/authorize`;
  chrome.tabs.create({ url: authURL }, (tab) => {
    // 监听回调页面消息
    chrome.tabs.onUpdated.addListener(handleAuthCallback);
  });
  ```

##### 3.3 双令牌安全机制
- **Token类型**
  - Access Token：有效期15分钟，用于API调用
  - Refresh Token：有效期14天，用于刷新Access Token
- **自动刷新机制**
  ```javascript
  // 令牌自动刷新
  setInterval(async () => {
    if (isTokenExpiringSoon()) {
      await refreshAccessToken();
    }
  }, 60000); // 每分钟检查一次
  ```

### 4. 简历数据管理

#### 功能描述
支持简历上传、解析、编辑和管理，为智能填表提供数据支撑。

#### 核心特点
- **多格式支持**
  - PDF文件解析
  - Word文档解析(.doc/.docx)
  - 在线编辑器
- **智能信息提取**
  - OCR文字识别
  - 结构化数据解析
  - 语义信息理解
- **数据标准化**
  - 统一字段格式
  - 数据验证和清洗
  - 缺失信息补全提示

#### 简历数据结构
```typescript
interface ResumeData {
  basicInfo: {
    name: string;           // 姓名
    gender: string;         // 性别
    phone: string;          // 联系电话
    email: string;          // 邮箱地址
    birthday: string;       // 出生日期
    idCard?: string;        // 身份证号
    address?: string;       // 居住地址
  };

  education: Array<{
    school: string;         // 学校名称
    major: string;          // 专业名称
    education: string;      // 学历层次
    degree: string;         // 学位类型
    startDate: string;      // 入学时间
    endDate: string;        // 毕业时间
    gpa?: number;          // 绩点
  }>;

  experience: Array<{
    company: string;        // 公司名称
    position: string;       // 职位名称
    department?: string;    // 部门
    startDate: string;      // 开始时间
    endDate?: string;       // 结束时间（为空表示至今）
    description: string;    // 工作描述
    achievements?: string[];// 主要成就
  }>;

  skills: Array<{
    category: string;       // 技能分类
    items: string[];        // 技能列表
    level?: string;         // 熟练程度
  }>;

  intention: {
    expectedSalary?: string;   // 期望薪资
    desiredPosition?: string;  // 期望职位
    desiredCity?: string;      // 期望工作地点
    jobType?: string;         // 工作类型（全职/兼职/实习）
    availableDate?: string;   // 到岗时间
  };
}
```
