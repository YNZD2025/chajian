## 🎯 产品概述

**一念职达助手**是一款基于AI技术的智能求职辅助浏览器扩展，旨在通过自动化技术简化求职流程，提升求职效率。

### 核心价值
- **AI赋能求职** - 运用先进的人工智能技术
- **一键直达理想Offer** - 简化求职流程，提高成功率
- **智能表单填写** - 自动识别并填写各类招聘网站表单

### 适用场景
- 各大招聘网站的职位申请表单
- 企业官网招聘页面
- 校园招聘在线申请系统
- HR系统职位申请表单

## 🚀 安装使用

### 系统要求
- Chrome浏览器 88+ 版本
- 稳定的网络连接
- 一念职达账号（可免费注册）

### 安装步骤

#### 1. 下载安装包
从官方渠道下载最新版本的扩展安装包

#### 2. 启用开发者模式
1. 打开Chrome浏览器
2. 访问 `chrome://extensions/`
3. 开启右上角的"开发者模式"

#### 3. 加载扩展
1. 点击"加载已解压的扩展程序"
2. 选择解压后的扩展文件夹
3. 确认安装

#### 4. 验证安装
- 浏览器工具栏出现🎯图标
- 点击图标可打开扩展面板

## 📖 详细功能说明

### 登录认证

#### 邮箱登录
1. 点击浏览器工具栏的🎯图标
2. 在弹出面板中输入邮箱/用户名和密码
3. 可选择"记住我"以保持登录状态
4. 点击"邮箱登录"完成认证

#### 注册新账号
1. 在登录面板中点击"还没有账号？立即注册"
2. 填写用户名、邮箱、密码等信息
3. 确认密码后点击"注册账号"
4. 注册成功后自动登录

#### 微信登录
1. 点击"微信扫码登录"
2. 系统打开新标签页显示二维码
3. 使用微信扫描二维码授权
4. 授权成功后自动返回并登录

### 智能填表功能

#### 启动自动填表
1. **悬浮按钮方式**：
   - 页面右下角会出现🎯悬浮按钮
   - 点击按钮打开对话窗口
   - 输入"开始填写"或"启动"等指令

2. **直接操作方式**：
   - 在对话窗口中直接说明填写需求
   - AI助手会自动识别意图并启动填表

#### 填表过程控制
- **暂停填写**：输入"暂停"或"停止"
- **继续填写**：输入"继续"或"恢复"
- **查看进度**：系统会实时显示填写进度

#### 填写结果确认
- 系统会高亮显示已填写的字段
- 显示填写成功/失败的统计信息
- 支持手动调整填写内容

### 悬浮助手控制

#### 悬浮按钮操作
- **单击**：打开/关闭对话窗口
- **长按**：打开设置菜单
- **右键**：快速访问设置选项

#### 设置菜单选项
- **常驻显示**：设置按钮是否常驻页面
- **隐藏按钮**：临时隐藏悬浮按钮（刷新页面恢复）

#### 扩展面板控制
在浏览器扩展面板中可以：
- 全局开启/关闭悬浮按钮
- 查看当前登录状态
- 访问快捷功能入口

### 简历管理

#### 简历上传
1. 登录后访问个人中心
2. 在简历管理页面上传简历文件
3. 系统自动解析简历信息
4. 确认并保存简历数据

#### 简历数据
系统支持以下简历字段：
- **基本信息**：姓名、性别、手机、邮箱、生日等
- **教育背景**：学校、专业、学历、学位等
- **工作经历**：公司、职位、工作描述等
- **求职意向**：期望薪资、期望职位、期望城市等

## ❓ 常见问题

### 安装相关

**Q: 安装后图标不显示怎么办？**
A: 检查是否正确启用了开发者模式，并确认扩展已正确加载。可以在 `chrome://extensions/` 页面查看扩展状态。

**Q: 扩展显示"上下文失效"错误？**
A: 这通常发生在扩展更新后。请刷新当前页面，或重新加载扩展程序。

### 登录相关

**Q: 无法登录怎么办？**
A: 请检查：
- 网络连接是否正常
- 账号密码是否正确
- 是否正确配置了服务器地址

**Q: 微信登录二维码不显示？**
A: 检查浏览器是否阻止了弹窗，需要允许来自该扩展的弹窗。

### 填表相关

**Q: 填表功能不工作？**
A: 请确认：
- 已正确登录账号
- 已上传简历信息
- 当前页面包含可填写的表单

**Q: 填写内容不准确怎么办？**
A: 可以：
- 手动修改填写结果
- 更新简历信息以提高匹配度
- 联系技术支持反馈问题

### 性能相关

**Q: 扩展影响浏览器性能？**
A: 扩展设计为轻量级，正常使用不会显著影响性能。如遇问题可临时禁用扩展。

**Q: 悬浮按钮可以关闭吗？**
A: 可以在扩展面板中关闭悬浮按钮，或使用右键菜单隐藏。
