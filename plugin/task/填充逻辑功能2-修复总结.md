## 🎯 需要解决的三个核心问题

### 问题 1：输入框填充后下拉选项未选择导致回滚
**现象**：
- 部分输入框填充后会弹出下拉框
- 需要选择下拉框的选项后，才会正常填充
- 否则切换到下个输入框后，原有填充内容因为没有选择导致回滚变成未填充

**根本原因**：
1. 监控时间太短（200ms），某些下拉框渲染需要更长时间
2. 没有找到匹配选项时，直接关闭弹窗导致输入的值被回滚
3. 缺少对弹窗是否真的出现的判断

### 问题 2：日期选择器处理不完善
**现象**：
- 部分日期框是根据年份选择月份（年月模式）
- 部分则是直接选择年份（年月日模式）
- 需要做判断实现不同需求

**根本原因**：
1. 当前逻辑假设所有日期选择器都是年月日三段式
2. 没有处理需要点击头部年份才能弹出年份列表的情况
3. 没有处理只需要年月的情况

### 问题 3：下拉框选项没有正常选择
**现象**：
- 下拉框点击后选项没有被正确选中

**根本原因**：
1. 等待时间不够（300ms）
2. 点击选项后没有等待足够的时间让选项被选中
3. 缺少选中确认机制
4. 原生 SELECT 事件触发不完整

### 修复 1：增强输入框填充后的监听机制

**修改位置**：`js/content.js` 第 3729-3774 行

**关键改进**：

1. **增加监控时间**
   ```javascript
   // 从 200ms 增加到 500ms
   await sleep(500); // 增加监控时间，确保下拉框完全渲染
   ```

2. **增加弹窗存在性检测**
   ```javascript
   // 检查是否真的有新弹窗出现
   const hasPopup = newlyAddedElements.length > 0 &&
                   newlyAddedElements.some(el => isElementVisible(el));
   ```

3. **改进未找到选项时的处理**
   ```javascript
   if (matchingOption) {
     // 找到选项：点击并等待
     await clickElement(matchingOption);
     await sleep(300); // 等待选项被选中
   } else {
     console.log(`⚠️ 未找到匹配选项，触发失焦保留输入值`);
     // 不关闭弹窗，而是触发失焦事件，让输入框保留值
     element.blur();
     await sleep(200);
     // 如果弹窗还在，尝试点击页面其他位置关闭
     if (newlyAddedElements.some(el => isElementVisible(el))) {
       const event = new MouseEvent('mousedown', { bubbles: true, cancelable: true });
       document.body.dispatchEvent(event);
     }
   }
   ```

4. **没有弹窗时直接失焦**
   ```javascript
   // 没有弹窗，直接失焦确保值被保留
   element.blur();
   await sleep(100);
   ```

### 修复 2：改进日期选择器逻辑

**修改位置**：`js/content.js` 第 3629-3790 行

**关键改进**：

1. **支持年月和年月日两种模式**
   ```javascript
   const year = dateMatch[1];
   const month = dateMatch[2];
   const day = dateMatch[3]; // 可能为 undefined（年月选择器）

   console.log(`📅 尝试选择日期: ${year}-${month}${day ? '-' + day : ''}`);
   ```

2. **支持多步骤年份选择**
   ```javascript
   // 先尝试直接选择年份
   let yearSelected = await findAndClick(container, yearHeaderPatterns, '年份');

   // 如果没有找到，尝试查找年份选择按钮（通常在日期选择器头部）
   if (!yearSelected) {
     const headerElements = Array.from(container.querySelectorAll('*'))
       .filter(el => {
         const text = el.textContent.trim();
         return /\d{4}\s*年?/.test(text) && text.length < 15;
       });

     if (headerElements.length > 0) {
       console.log(`✓ 找到年份头部，点击展开年份列表`);
       await clickElement(headerElements[0]);
       await sleep(500);

       // 重新监控 DOM 变化，查找弹出的年份列表
       startMonitoringDomChanges();
       await sleep(300);
       stopMonitoringDomChanges();

       // 在新弹出的元素中查找目标年份
       for (const newContainer of newlyAddedElements) {
         yearSelected = await findAndClick(newContainer, yearHeaderPatterns, '年份');
         if (yearSelected) break;
       }
     }
   }
   ```

3. **动态重新获取容器**
   ```javascript
   // 年份选择后界面可能已变化，重新获取可见容器
   startMonitoringDomChanges();
   await sleep(200);
   stopMonitoringDomChanges();

   const visibleContainers = newlyAddedElements.length > 0 ?
                            newlyAddedElements : [container];
   ```

4. **区分年月和年月日模式**
   ```javascript
   // 第三步：如果有日期，选择日期
   if (day && monthSelected) {
     // 年月日模式：继续选择日期
     // ...
   } else if (!day) {
     // 年月选择器，月份选择后直接完成
     console.log(`✅ 年月选择完成`);
     await sleep(200);
     return true;
   }
   ```

5. **改进元素查找策略**
   ```javascript
   const findAndClick = async (container, patterns, name) => {
     const elements = Array.from(container.querySelectorAll('*'))
       .filter(el => {
         if (el.children.length > 3) return false; // 跳过容器元素
         const text = el.textContent.trim();
         return patterns.some(pattern => {
           if (typeof pattern === 'string') {
             return text === pattern;
           } else if (pattern instanceof RegExp) {
             return pattern.test(text);
           }
           return false;
         });
       });

     if (elements.length > 0) {
       console.log(`✓ 找到${name}: "${elements[0].textContent.trim()}"`);
       await clickElement(elements[0]);
       await sleep(400);
       return true;
     }
     return false;
   };
   ```

### 修复 3：修复下拉框选项选择问题

**修改位置**：`js/content.js` 第 3889-3948 行（自定义下拉框）和 3950-4021 行（原生 SELECT）

**关键改进**：

#### 3.1 自定义下拉框

1. **增加等待时间**
   ```javascript
   // 从 300ms 增加到 500ms
   await sleep(500); // 增加等待时间，确保下拉选项完全渲染
   ```

2. **增加弹窗检测和重试**
   ```javascript
   // 检查是否真的有弹窗出现
   const hasVisiblePopup = newlyAddedElements.length > 0 &&
                          newlyAddedElements.some(el => isElementVisible(el));

   if (!hasVisiblePopup) {
     console.log(`⚠️ 点击后未检测到下拉选项弹窗`);
     // 尝试再点击一次
     await clickElement(element);
     await sleep(300);
   }
   ```

3. **增加选中后的等待和验证**
   ```javascript
   if (matchingOption) {
     await clickElement(matchingOption);
     await sleep(400); // 增加等待时间，确保选项被完全选中

     // 验证选择是否成功
     await sleep(200);
     const currentValue = element.value || element.textContent.trim();
     console.log(`🔍 验证选择结果，当前值: "${currentValue}"`);
   }
   ```

4. **增加调试信息**
   ```javascript
   console.log(`可用选项: `, newlyAddedElements.map(el =>
     Array.from(el.querySelectorAll('*'))
       .filter(opt => opt.children.length === 0)
       .map(opt => opt.textContent.trim())
       .filter(t => t.length > 0)
       .slice(0, 10)
   ));
   ```

#### 3.2 原生 SELECT

1. **创建统一的事件触发函数**
   ```javascript
   const triggerSelectEvents = (selectElement, optionValue) => {
     selectElement.value = optionValue;
     selectElement.focus();

     // 触发所有必要的事件，确保各种框架都能捕获
     selectElement.dispatchEvent(new Event("input", { bubbles: true, cancelable: true }));
     selectElement.dispatchEvent(new Event("change", { bubbles: true, cancelable: true }));
     selectElement.dispatchEvent(new Event("blur", { bubbles: true, cancelable: true }));

     // 某些框架可能需要这些事件
     const clickEvent = new MouseEvent('click', { bubbles: true, cancelable: true });
     selectElement.dispatchEvent(clickEvent);
   };
   ```

2. **在所有匹配分支中使用统一的事件触发**
   ```javascript
   // 精确匹配 value 属性
   if (normalize(option.value) === normalizedValue) {
     triggerSelectEvents(element, option.value);
     console.log(`✅ SELECT 精确匹配(value): "${value}"`);
     return true;
   }

   // 其他匹配分支同样使用 triggerSelectEvents
   ```

## 🎯 核心改进点总结

### 1. 时间策略优化
- **监控时间增加**：从 200-300ms 增加到 500ms
- **等待时间增加**：选项点击后等待从 200ms 增加到 300-400ms
- **验证等待**：增加了选中后的验证等待时间

### 2. 检测机制增强
- **弹窗存在性检测**：确保真的有弹窗出现才进行后续操作
- **可见性检查**：检查元素是否真的可见
- **重试机制**：下拉框点击后未检测到弹窗时自动重试

### 3. 事件触发完善
- **输入框**：input + change + InputEvent + blur
- **SELECT**：input + change + blur + click
- **失焦处理**：未找到选项时触发失焦而不是关闭弹窗

### 4. 智能识别能力
- **日期类型识别**：区分年月和年月日
- **多步骤支持**：支持点击头部展开的年份选择器
- **动态容器获取**：根据界面变化重新获取容器

## 🐛 已知限制

1. **日期选择器兼容性**
   - 依赖特征识别（周一到周日、数字网格）
   - 部分自定义样式的选择器可能无法识别
   - **降级方案**：失败时尝试直接输入

2. **自定义下拉框**
   - 需要弹出 DOM 元素才能识别
   - 虚拟滚动的下拉列表可能无法完全匹配
   - **降级方案**：显示可用选项列表供调试

3. **等待时间平衡**
   - 增加等待时间提高成功率，但也增加了填充总时长
   - 500ms 是经过权衡的值，可根据实际情况调整
