## 📋 文件概述

**文件名**: `resume-data.json`
**用途**: 用于填充表单的完整简历数据，对应 `localGroups` 结构
**数据来源**: 基于 `resume.json` 并扩展到完整字段定义
**生成时间**: 2025-11-27


## 🚀 使用方法

### 1. 在填充逻辑中使用
```javascript
// 读取完整数据
const fillValues = require('./task/resume-data.json');

// 调用填充函数
await performFilling(localGroups, fillValues);
```

### 2. 与 localGroups 的对应关系
```javascript
// resume-data.json 的结构直接对应 performFilling 的第二个参数
localGroups = [
  {
    name: "基本信息",        // 分组名称（用于匹配）
    dom: {},                 // 页面 DOM 元素
    fields: [
      {
        name: "姓名",        // 字段名称（用于匹配）
        originalField: {},   // 服务器字段定义
        field: { dom: {} },  // 字段 DOM 元素
        blanks: [
          {
            name: "",        // 输入框标签
            dom: {},         // 输入框 DOM
            type: "input"    // 输入框类型
          }
        ]
      }
    ]
  }
];

fillValues = [  // 来自 resume-data.json
  {
    name: "基本信息",        // 匹配 localGroups[i].name
    fields: [
      {
        name: "姓名",        // 匹配 localGroups[i].fields[j].name
        blanks: [
          { value: "fly" }   // 填充到 localGroups[i].fields[j].blanks[k].dom
        ]
      }
    ]
  }
];
```

## 🔧 字段匹配规则

### 1. 分组名称匹配
- **精确匹配**: 优先使用完全相同的分组名称
- **模糊匹配**: 支持近似匹配（如"基本信息" 匹配 "个人信息"）

### 2. 字段名称匹配
- **精确匹配**: 字段名完全相同（如"姓名" = "姓名"）
- **包含匹配**: 字段名包含关系（如"姓名*" 包含 "姓名"）
- **类型匹配**: 根据 fieldType 匹配（如 phone 类型匹配手机号字段）

### 3. 多值字段处理
- **手机号**: 自动分离国家代码和号码
- **日期范围**: 自动识别起始和结束时间
- **地区多选**: 支持分隔符（/ 、 , ，）分割多个地区

---

## 📌 注意事项

### 1. 数据格式
- ✅ 日期格式: YYYY-MM 或 YYYY
- ✅ 手机号: 分为两个值 ["+86", "16673570000"]
- ✅ 长文本: 使用 \n 表示换行

### 2. 空值处理
- 空字符串 `""`: 字段存在但值为空
- 空数组 `[]`: 不填充该字段（如附件上传）

### 3. 字段顺序
- 数据顺序应与页面字段顺序保持一致
- 如果页面没有某个分组，该分组会被自动跳过
