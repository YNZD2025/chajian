# 调试步骤

## 1. 重新加载扩展
1. 打开 Chrome 扩展管理页面：`chrome://extensions/`
2. 找到"一念职达"扩展
3. 点击"重新加载"按钮（刷新图标）
4. 刷新测试页面

## 2. 检查 yn-ai 元素是否存在
1. 在测试页面按 F12 打开开发者工具
2. 在 Console 中输入以下命令：
   ```javascript
   document.getElementById('yn-ai')
   ```
3. 如果返回 `null`，说明元素没有创建成功
4. 如果返回一个 DOM 元素，说明元素创建成功

## 3. 检查控制台错误
1. 打开开发者工具的 Console 标签页
2. 查看是否有任何错误信息（红色文字）
3. 特别注意与 `yn-ai` 相关的错误

## 4. 检查按钮是否可见
1. 在 Console 中输入：
   ```javascript
   const ynAi = document.getElementById('yn-ai');
   const shadowRoot = ynAi?.shadowRoot;
   const button = shadowRoot?.getElementById('logo-button');
   console.log('按钮元素:', button);
   console.log('按钮样式:', button ? getComputedStyle(button).display : 'button不存在');
   ```

## 5. 手动触发窗口打开
1. 如果按钮存在但点击无效，尝试在 Console 中手动触发：
   ```javascript
   const ynAi = document.getElementById('yn-ai');
   const shadowRoot = ynAi?.shadowRoot;
   const button = shadowRoot?.getElementById('logo-button');
   if (button) {
       button.click();
   }
   ```

## 6. 检查事件监听器
1. 在 Elements 标签页中找到 logo-button 元素
2. 右键点击 -> Event Listeners
3. 检查是否有 click 事件监听器

## 常见问题修复

### 如果元素没有创建
- 检查 content_scripts 是否正确加载
- 查看 manifest.json 中的 content_scripts 配置

### 如果按钮不可见
- 检查 z-index 是否被覆盖
- 检查 display 属性
- 检查是否被其他元素遮挡

### 如果点击无响应
- 检查事件监听器是否正确绑定
- 检查是否有 JavaScript 错误阻止了代码执行
