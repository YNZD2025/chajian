## 📝 使用说明

### 1. 字段类型匹配
当填充表单时，`valueByType` 函数会根据字段的 `fieldType` 属性返回对应的默认值：

```javascript
// 示例
const fieldType = "desiredcity";
const value = valueByType(fieldType); // 返回 "深圳"
```

### 2. 降级机制
部分字段（如 school、major）会先尝试从 `resumeMd` 中提取，如果失败则使用默认值：

```javascript
case "school": return getMd("School") || "湖南软件职业技术大学";
//                    ↑ 优先从 MD 提取    ↑ 失败时使用默认值
```

### 3. 动态值
company 和 position 字段支持从函数参数动态传入：

```javascript
case "company": return company || "北京人人众包科技有限公司";
//                     ↑ 优先使用传入值    ↑ 无传入值时使用默认
```
