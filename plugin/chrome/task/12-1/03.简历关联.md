# 需求
- 简历关联
- 状态锁定

# 关联代码
- 插件：@chrome/js2/resumeInterfaceTwo.js
- 插件：@chrome/js2/contentTwo.js

# 需求描述
- 简历关联：我刚刚已经完成，初始化的时候，从resumeInterfaceTwo.js中获取简历数据，然后填充到fill.html中。现在需要将选中的简历，也就是展示的简历，将他的id关联到contentTwo.js中，方便后续的操作，比如自动填充，点击自动填充，将选中的简历的id，发送到contentTwo.js中，同时如果切换了简历，比如切换下一份简历后，需要更新这个简历id，传递过去。
- 状态锁定：我需要在fill.html中，添加一个状态锁定的功能，当用户点击自动填充按钮时，需要将当前展示的简历的状态锁定，防止用户切换到其他简历后，点击自动填充，填充了错误的简历。如果用户在填充过程中，切换了简历，需要提示用户，当前展示的简历已被锁定，不能切换。
