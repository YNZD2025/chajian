# 需求
- 根据简历列表，展示每个简历的数据

# 涉及代码
- @/js2/resumeInterfaceTwo.js
- @/popup/fill.html

# 功能描述
点击按钮打开填充页面，填充页面中间展示简历的详细数据，fill.html已经设置了，从class=plugin-content这个盒子开始，info-cell-label是标题，而info-cell-value是值，需要根据简历数据，填充到对应的位置。

# 需求实现
需要初始化的时候，从resumeInterfaceTwo.js中获取简历数据，然后填充到fill.html中，后端返回的是一个简历列表，字段有简历ID、简历名称（区分简历）、学校、学历、专业、毕业年份、手机、邮箱、意向岗位、期望城市、核心技能，对应英文名：resumeId、resumeName、school、education、major、graduationYear、phone、email、intentionJob、expectCity、coreSkills。接口调用先调用getResumeList接口，获取简历列表，每条简历都有这些简历详情，最后填充到fill.html中。获取简历接口用 "todo 简历接口" 表示，方便修改
