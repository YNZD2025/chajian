# Chrome扩展外部消息通信说明

## 问题诊断

### 为什么 `chrome.runtime.onMessageExternal` 没有监听到消息？

**常见原因：**

1. **使用了错误的API**
   - ❌ 错误：使用 `window.postMessage()`
   - ✅ 正确：使用 `chrome.runtime.sendMessage(extensionId, message)`

2. **未配置 `externally_connectable`**
   - 必须在 `manifest.json` 中配置允许通信的域名

3. **扩展ID错误**
   - 发送消息时需要使用正确的扩展ID

## 正确的通信方式

### 1. 扩展端配置 (已完成)

**manifest.json**
```json
{
  "externally_connectable": {
    "matches": [
      "http://192.168.1.144:*/*",
      "http://localhost:*/*",
      "https://applymind.cn/*"
    ]
  }
}
```

**background.js**
```javascript
chrome.runtime.onMessageExternal.addListener((message, sender, sendResponse) => {
    console.log("收到来自外部网站的消息:", message);

    if (message.type === "login") {
        // 处理登录
        AuthModule.handleExternalLogin(message, sendResponse);
    } else if (message.type === "logout") {
        // 处理登出
        AuthModule.handleExternalLogout(sendResponse);
    } else if (message.type === "ping") {
        // 测试连接
        sendResponse({ status: "pong", version: "1.0.0" });
    }

    return true; // 保持消息通道开启
});
```

### 2. 网站端发送消息

**方法一：使用扩展ID（推荐）**

```javascript
// 获取扩展ID的方法：
// 1. 打开 chrome://extensions/
// 2. 开启"开发者模式"
// 3. 找到"一念职达"扩展，复制ID

const EXTENSION_ID = 'your-extension-id-here'; // 替换为实际ID

// 发送登录消息
chrome.runtime.sendMessage(
    EXTENSION_ID,
    {
        type: 'login',
        data: {
            token: {
                accessToken: 'your-access-token',
                refreshToken: 'your-refresh-token',
                userInfo: {
                    userId: '123',
                    username: '用户名',
                    email: 'user@example.com'
                }
            }
        }
    },
    function(response) {
        if (chrome.runtime.lastError) {
            console.error('发送失败:', chrome.runtime.lastError.message);
        } else {
            console.log('发送成功:', response);
        }
    }
);
```

**方法二：动态获取扩展ID**

如果你的网站和扩展是配套的，可以在扩展中暴露ID：

```javascript
// 在扩展的content script中
window.addEventListener('message', (event) => {
    if (event.data.type === 'GET_EXTENSION_ID') {
        event.source.postMessage({
            type: 'EXTENSION_ID_RESPONSE',
            extensionId: chrome.runtime.id
        }, event.origin);
    }
});
```

```javascript
// 在网站中获取扩展ID
function getExtensionId() {
    return new Promise((resolve) => {
        window.addEventListener('message', (event) => {
            if (event.data.type === 'EXTENSION_ID_RESPONSE') {
                resolve(event.data.extensionId);
            }
        });
        window.postMessage({ type: 'GET_EXTENSION_ID' }, '*');
    });
}

// 使用
const extensionId = await getExtensionId();
chrome.runtime.sendMessage(extensionId, { type: 'login', ... });
```

## 调试技巧

### 1. 检查externally_connectable配置

确保你的网站域名在 `manifest.json` 的 `externally_connectable.matches` 中：

```json
{
  "externally_connectable": {
    "matches": [
      "http://localhost:*/*",      // 本地开发
      "http://192.168.1.144:*/*", // 局域网IP
      "https://applymind.cn/*"     // 生产域名
    ]
  }
}
```

### 2. 常见错误信息

| 错误信息 | 原因 | 解决方法 |
|---------|------|---------|
| `Could not establish connection` | 扩展未安装或已禁用 | 检查扩展状态 |
| `Receiving end does not exist` | 扩展ID错误 | 检查扩展ID是否正确 |
| `Access to extension denied` | 域名未配置 | 添加到 externally_connectable |

### 3. 调试代码

在 `background.js` 中添加详细日志：

```javascript
chrome.runtime.onMessageExternal.addListener((message, sender, sendResponse) => {
    console.log('=== 收到外部消息 ===');
    console.log('消息类型:', message.type);
    console.log('消息内容:', message);
    console.log('发送者URL:', sender.url);
    console.log('发送者Tab ID:', sender.tab?.id);
    console.log('==================');

    // ... 处理消息

    return true;
});
```

## 完整示例：登录页面集成

```html
<!DOCTYPE html>
<html>
<head>
    <title>登录 - 一念职达</title>
</head>
<body>
    <form id="loginForm">
        <input type="text" id="username" placeholder="用户名">
        <input type="password" id="password" placeholder="密码">
        <button type="submit">登录</button>
    </form>

    <script>
        const EXTENSION_ID = 'your-extension-id-here';

        document.getElementById('loginForm').addEventListener('submit', async (e) => {
            e.preventDefault();

            // 1. 调用后端登录API
            const response = await fetch('/api/login', {
                method: 'POST',
                headers: { 'Content-Type': 'application/json' },
                body: JSON.stringify({
                    username: document.getElementById('username').value,
                    password: document.getElementById('password').value
                })
            });

            const data = await response.json();

            if (data.success) {
                // 2. 发送登录信息到Chrome扩展
                chrome.runtime.sendMessage(
                    EXTENSION_ID,
                    {
                        type: 'login',
                        data: {
                            token: {
                                accessToken: data.accessToken,
                                refreshToken: data.refreshToken,
                                userInfo: data.userInfo
                            }
                        }
                    },
                    (response) => {
                        if (chrome.runtime.lastError) {
                            console.warn('扩展同步失败:', chrome.runtime.lastError.message);
                            // 不影响登录流程，继续执行
                        } else {
                            console.log('扩展同步成功:', response);
                        }

                        // 3. 跳转到主页
                        window.location.href = '/dashboard';
                    }
                );
            }
        });
    </script>
</body>
</html>
```

## 常见问题 FAQ

### Q1: 如何获取扩展ID？
**A:** 打开 `chrome://extensions/` -> 启用开发者模式 -> 查看扩展卡片上的ID

### Q2: 为什么本地测试时无法发送消息？
**A:** 确保在 `externally_connectable` 中添加了 `http://localhost:*/*`

### Q3: 如何在生产环境中使用？
**A:**
1. 发布扩展到Chrome Web Store后，ID会固定
2. 在网站代码中硬编码该ID
3. 或者在网站后端配置中管理扩展ID

### Q4: 如何处理扩展未安装的情况？
**A:**
```javascript
try {
    chrome.runtime.sendMessage(EXTENSION_ID, message, (response) => {
        if (chrome.runtime.lastError) {
            // 扩展未安装或未启用
            console.log('扩展未安装，跳过同步');
        } else {
            console.log('同步成功');
        }
    });
} catch (error) {
    // chrome.runtime API 不存在（非Chrome浏览器）
    console.log('非Chrome浏览器，跳过扩展同步');
}
```
