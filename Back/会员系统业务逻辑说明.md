## 设计理念

### 🎯 核心思想：VIP时长叠加池

**传统方式的问题**：
- 只能记录一个过期时间
- 购买低等级VIP会"浪费"高等级时长
- 升级时需要复杂的价值抵扣计算

**我们的方案**：
- ✅ 各等级VIP天数独立存储（像三个独立的"时间池"）
- ✅ 购买任意等级都直接叠加到对应池中
- ✅ 自动使用最高等级的VIP
- ✅ 高等级用完自动降级使用次高等级
- ✅ 简历优化次数所有VIP共享叠加

## 数据库设计

### 核心表：user_membership

```sql
CREATE TABLE `user_membership` (
  `id` BIGINT NOT NULL AUTO_INCREMENT,
  `user_id` BIGINT NOT NULL,
  `monthly_vip_days` INT DEFAULT 0,      -- 月度VIP剩余天数
  `quarterly_vip_days` INT DEFAULT 0,    -- 季度VIP剩余天数
  `yearly_vip_days` INT DEFAULT 0,       -- 年度VIP剩余天数
  `resume_optimize_count` INT DEFAULT 3, -- 剩余优化次数（共享）
  `total_optimized` INT DEFAULT 0,       -- 累计已使用次数
  `is_author` TINYINT DEFAULT 0,         -- 是否作者（独立身份）
  `last_consume_date` DATE DEFAULT NULL, -- 最后消费日期
  `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP,
  `updated_at` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `idx_user_id` (`user_id`)
);
```

### 字段说明

| 字段 | 说明 | 示例 |
|------|------|------|
| monthly_vip_days | 月度VIP剩余天数 | 30 |
| quarterly_vip_days | 季度VIP剩余天数 | 90 |
| yearly_vip_days | 年度VIP剩余天数 | 365 |
| resume_optimize_count | 所有VIP共享的优化次数 | 630 |
| is_author | 作者身份（与VIP无关） | 0/1 |
| last_consume_date | 防止重复消费VIP天数 | 2025-01-15 |

## 核心业务逻辑

### 1️⃣ 当前VIP等级计算

**优先级：年度VIP > 季度VIP > 月度VIP > 普通用户**

```java
public Integer getCurrentLevel(UserMembership membership) {
    if (membership.getYearlyVipDays() > 0) {
        return 3; // 年度VIP
    } else if (membership.getQuarterlyVipDays() > 0) {
        return 2; // 季度VIP
    } else if (membership.getMonthlyVipDays() > 0) {
        return 1; // 月度VIP
    } else {
        return 0; // 普通用户
    }
}
```

### 2️⃣ 购买VIP（叠加逻辑）

```java
@Transactional
public void purchaseMembership(Long userId, Integer level, Long orderId) {
    UserMembership membership = membershipMapper.selectByUserId(userId);
    
    // 获取配置
    Integer days = getMembershipDays(level);
    Integer optimizeCount = getMembershipOptimizeCount(level);
    
    // 叠加天数和次数
    switch (level) {
        case 1: // 月度VIP
            membership.setMonthlyVipDays(
                membership.getMonthlyVipDays() + days
            );
            break;
        case 2: // 季度VIP
            membership.setQuarterlyVipDays(
                membership.getQuarterlyVipDays() + days
            );
            break;
        case 3: // 年度VIP
            membership.setYearlyVipDays(
                membership.getYearlyVipDays() + days
            );
            break;
    }
    
    // 优化次数叠加
    membership.setResumeOptimizeCount(
        membership.getResumeOptimizeCount() + optimizeCount
    );
    
    membershipMapper.updateById(membership);
    
    // 记录变更历史
    logMembershipChange(userId, "purchase", level, days, optimizeCount, orderId);
}
```

### 3️⃣ 每日消费VIP天数（定时任务）

**定时任务：每天凌晨1点执行**

```java
@Scheduled(cron = "0 0 1 * * ?")
@Transactional
public void consumeVipDaysDaily() {
    // 查询所有有VIP的用户
    List<UserMembership> list = membershipMapper.selectActiveVipUsers();
    
    LocalDate today = LocalDate.now();
    
    for (UserMembership membership : list) {
        // 防止重复消费
        if (membership.getLastConsumeDate() != null && 
            !membership.getLastConsumeDate().isBefore(today)) {
            continue;
        }
        
        // 按优先级消费
        if (membership.getYearlyVipDays() > 0) {
            membership.setYearlyVipDays(membership.getYearlyVipDays() - 1);
        } else if (membership.getQuarterlyVipDays() > 0) {
            membership.setQuarterlyVipDays(membership.getQuarterlyVipDays() - 1);
        } else if (membership.getMonthlyVipDays() > 0) {
            membership.setMonthlyVipDays(membership.getMonthlyVipDays() - 1);
        }
        
        membership.setLastConsumeDate(today);
        membershipMapper.updateById(membership);
        
        // 记录消费历史
        logMembershipChange(membership.getUserId(), "consume", 
            getCurrentLevel(membership), -1, 0, null);
    }
}
```

**SQL版本（单个用户）**：
```sql
UPDATE user_membership
SET yearly_vip_days = CASE 
      WHEN yearly_vip_days > 0 THEN yearly_vip_days - 1
      ELSE 0
    END,
    quarterly_vip_days = CASE 
      WHEN yearly_vip_days = 0 AND quarterly_vip_days > 0 THEN quarterly_vip_days - 1
      ELSE quarterly_vip_days
    END,
    monthly_vip_days = CASE 
      WHEN yearly_vip_days = 0 AND quarterly_vip_days = 0 AND monthly_vip_days > 0 
      THEN monthly_vip_days - 1
      ELSE monthly_vip_days
    END,
    last_consume_date = CURDATE()
WHERE user_id = 1
  AND (yearly_vip_days > 0 OR quarterly_vip_days > 0 OR monthly_vip_days > 0)
  AND (last_consume_date IS NULL OR last_consume_date < CURDATE());
```

### 4️⃣ 使用简历优化

```java
public boolean useResumeOptimize(Long userId) {
    UserMembership membership = membershipMapper.selectByUserId(userId);
    
    if (membership.getResumeOptimizeCount() <= 0) {
        throw new BusinessException("优化次数不足");
    }
    
    membership.setResumeOptimizeCount(
        membership.getResumeOptimizeCount() - 1
    );
    membership.setTotalOptimized(
        membership.getTotalOptimized() + 1
    );
    
    membershipMapper.updateById(membership);
    return true;
}
```

## Java代码实现

### MembershipService 完整实现

```java
@Service
public class MembershipService {
    
    @Autowired
    private UserMembershipMapper membershipMapper;
    
    @Autowired
    private MembershipChangeLogMapper changeLogMapper;
    
    /**
     * 获取用户会员信息（含当前等级）
     */
    public MembershipVO getUserMembership(Long userId) {
        UserMembership membership = membershipMapper.selectByUserId(userId);
        if (membership == null) {
            // 创建默认记录
            membership = createDefaultMembership(userId);
        }
        
        MembershipVO vo = new MembershipVO();
        BeanUtils.copyProperties(membership, vo);
        
        // 计算当前等级
        vo.setCurrentLevel(getCurrentLevel(membership));
        vo.setCurrentLevelName(getLevelName(vo.getCurrentLevel()));
        
        // 计算总VIP天数
        vo.setTotalVipDays(
            membership.getMonthlyVipDays() + 
            membership.getQuarterlyVipDays() + 
            membership.getYearlyVipDays()
        );
        
        // 判断是否VIP
        vo.setIsVip(vo.getCurrentLevel() > 0);
        
        return vo;
    }
    
    /**
     * 购买会员
     */
    @Transactional
    public PurchaseResult purchaseMembership(Long userId, Integer level, Long orderId) {
        UserMembership membership = membershipMapper.selectByUserId(userId);
        if (membership == null) {
            membership = createDefaultMembership(userId);
        }
        
        // 获取配置
        Integer days = getMembershipDays(level);
        Integer optimizeCount = getMembershipOptimizeCount(level);
        BigDecimal price = getMembershipPrice(level);
        
        // 记录变更前状态
        Integer oldMonthly = membership.getMonthlyVipDays();
        Integer oldQuarterly = membership.getQuarterlyVipDays();
        Integer oldYearly = membership.getYearlyVipDays();
        Integer oldOptimizeCount = membership.getResumeOptimizeCount();
        
        // 叠加天数
        switch (level) {
            case 1:
                membership.setMonthlyVipDays(oldMonthly + days);
                break;
            case 2:
                membership.setQuarterlyVipDays(oldQuarterly + days);
                break;
            case 3:
                membership.setYearlyVipDays(oldYearly + days);
                break;
            default:
                throw new BusinessException("无效的会员等级");
        }
        
        // 叠加优化次数
        membership.setResumeOptimizeCount(oldOptimizeCount + optimizeCount);
        
        membershipMapper.updateById(membership);
        
        // 记录变更历史
        MembershipChangeLog log = new MembershipChangeLog();
        log.setUserId(userId);
        log.setChangeType("purchase");
        log.setMembershipLevel(level);
        log.setDaysChange(days);
        log.setOptimizeCountChange(optimizeCount);
        log.setMonthlyVipDaysAfter(membership.getMonthlyVipDays());
        log.setQuarterlyVipDaysAfter(membership.getQuarterlyVipDays());
        log.setYearlyVipDaysAfter(membership.getYearlyVipDays());
        log.setOptimizeCountAfter(membership.getResumeOptimizeCount());
        log.setOrderId(orderId);
        log.setRemark("购买" + getLevelName(level));
        changeLogMapper.insert(log);
        
        return new PurchaseResult(price, getLevelName(level), days, optimizeCount);
    }
    
    /**
     * 计算当前等级
     */
    private Integer getCurrentLevel(UserMembership membership) {
        if (membership.getYearlyVipDays() > 0) return 3;
        if (membership.getQuarterlyVipDays() > 0) return 2;
        if (membership.getMonthlyVipDays() > 0) return 1;
        return 0;
    }
    
    /**
     * 获取等级名称
     */
    private String getLevelName(Integer level) {
        switch (level) {
            case 1: return "月度VIP";
            case 2: return "季度VIP";
            case 3: return "年度VIP";
            default: return "普通用户";
        }
    }
    
    /**
     * 从配置获取会员天数
     */
    private Integer getMembershipDays(Integer level) {
        String key = "membership_days_" + 
            (level == 1 ? "monthly" : level == 2 ? "quarterly" : "yearly");
        return Integer.parseInt(configService.getValue(key, "30"));
    }
    
    /**
     * 从配置获取优化次数
     */
    private Integer getMembershipOptimizeCount(Integer level) {
        String key = "membership_optimize_count_" + 
            (level == 1 ? "monthly" : level == 2 ? "quarterly" : "yearly");
        return Integer.parseInt(configService.getValue(key, "30"));
    }
    
    /**
     * 从配置获取价格
     */
    private BigDecimal getMembershipPrice(Integer level) {
        String key = "membership_price_" + 
            (level == 1 ? "monthly" : level == 2 ? "quarterly" : "yearly");
        return new BigDecimal(configService.getValue(key, "29.9"));
    }
    
    /**
     * 定时任务：每日消费VIP天数
     */
    @Scheduled(cron = "0 0 1 * * ?")
    @Transactional
    public void consumeVipDaysDaily() {
        List<UserMembership> list = membershipMapper.selectActiveVipUsers();
        LocalDate today = LocalDate.now();
        
        for (UserMembership membership : list) {
            // 防止重复消费
            if (membership.getLastConsumeDate() != null && 
                !membership.getLastConsumeDate().isBefore(today)) {
                continue;
            }
            
            Integer consumeLevel = null;
            
            // 按优先级消费
            if (membership.getYearlyVipDays() > 0) {
                membership.setYearlyVipDays(membership.getYearlyVipDays() - 1);
                consumeLevel = 3;
            } else if (membership.getQuarterlyVipDays() > 0) {
                membership.setQuarterlyVipDays(membership.getQuarterlyVipDays() - 1);
                consumeLevel = 2;
            } else if (membership.getMonthlyVipDays() > 0) {
                membership.setMonthlyVipDays(membership.getMonthlyVipDays() - 1);
                consumeLevel = 1;
            }
            
            if (consumeLevel != null) {
                membership.setLastConsumeDate(today);
                membershipMapper.updateById(membership);
                
                // 记录消费
                MembershipChangeLog log = new MembershipChangeLog();
                log.setUserId(membership.getUserId());
                log.setChangeType("consume");
                log.setMembershipLevel(consumeLevel);
                log.setDaysChange(-1);
                log.setOptimizeCountChange(0);
                log.setMonthlyVipDaysAfter(membership.getMonthlyVipDays());
                log.setQuarterlyVipDaysAfter(membership.getQuarterlyVipDays());
                log.setYearlyVipDaysAfter(membership.getYearlyVipDays());
                log.setOptimizeCountAfter(membership.getResumeOptimizeCount());
                log.setRemark("每日自动消费VIP天数");
                changeLogMapper.insert(log);
            }
        }
    }
}
```

## 使用场景

### 场景1：新用户购买月度VIP

```
初始状态：
  monthly_vip_days = 0
  quarterly_vip_days = 0
  yearly_vip_days = 0
  resume_optimize_count = 3
  当前等级 = 普通用户

购买月度VIP：
  monthly_vip_days = 0 + 30 = 30
  resume_optimize_count = 3 + 30 = 33
  当前等级 = 月度VIP
```

### 场景2：月度VIP用户升级年度VIP

```
当前状态：
  monthly_vip_days = 10（还剩10天）
  quarterly_vip_days = 0
  yearly_vip_days = 0
  当前等级 = 月度VIP

购买年度VIP：
  monthly_vip_days = 10（保持不变！）
  yearly_vip_days = 0 + 365 = 365
  当前等级 = 年度VIP（立即切换）

365天后：
  monthly_vip_days = 10
  yearly_vip_days = 0（用完了）
  当前等级 = 月度VIP（自动降级）

再过10天：
  monthly_vip_days = 0（用完了）
  当前等级 = 普通用户
```

### 场景3：混合购买叠加

```
操作序列：
1. 购买月度VIP（30天，30次）
2. 使用20天
3. 购买季度VIP（90天，100次）
4. 使用80天  
5. 购买年度VIP（365天，500次）

当前状态：
  monthly_vip_days = 10（30 - 20）
  quarterly_vip_days = 10（90 - 80）
  yearly_vip_days = 365
  resume_optimize_count = 630（30 + 100 + 500）
  当前等级 = 年度VIP

可用总天数 = 10 + 10 + 365 = 385天
消费顺序 = 先用365天年度 → 再用10天季度 → 最后用10天月度
```

### 场景4：作者身份

```
普通用户设置为作者：
  is_author = 1
  
作者权限：
  - 可以发布攻略文章
  - 不影响VIP状态
  
作者 + VIP：
  - 作者可以同时购买VIP
  - 享受VIP权益 + 作者权限
```

## 优势总结

### ✅ 相比传统方案的优势

1. **超级简单**：购买就是加法，不需要复杂计算
2. **用户友好**：买什么等级就加什么等级，清晰明了
3. **灵活叠加**：随时购买任意等级，自动叠加
4. **自动降级**：高等级用完自动用低等级，体验连续
5. **次数共享**：所有优化次数统一管理，不浪费
6. **容易理解**：像充值话费一样简单

### 📊 对比表

| 特性 | 传统方案 | 我们的方案 |
|------|---------|----------|
| 购买逻辑 | 需要计算抵扣 | 直接叠加 ✅ |
| 升级体验 | 立即生效，旧时长浪费 | 旧时长保留 ✅ |
| 降级购买 | 不允许或复杂计算 | 随意购买叠加 ✅ |
| 用户理解 | 复杂 | 简单直观 ✅ |
| 代码实现 | 复杂 | 简单 ✅ |

## 总结

这个**VIP时长叠加池**方案是最适合你需求的设计：

1. 🎯 **简单**：各等级独立存储，购买即叠加
2. 🔄 **灵活**：随时购买任意等级，自动优先使用高等级
3. 📈 **合理**：次数共享叠加，作者独立身份
4. 💡 **易懂**：用户一看就明白，开发一写就会

核心原则就一句话：**买什么加什么，用时优先用最好的！**
