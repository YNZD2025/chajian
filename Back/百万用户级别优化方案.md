# VIP系统百万用户级别优化方案

## 📊 性能分析

### 当前设计面临的挑战

#### 1. 定时任务压力
```
场景：100万VIP用户
每天凌晨执行：
  - 查询：SELECT * FROM user_membership WHERE ... (100万条)
  - 更新：UPDATE user_membership ... (100万次)
  - 插入：INSERT INTO membership_change_log ... (100万条)
  
问题：
  - 数据库连接池耗尽
  - 主从延迟严重
  - 锁等待超时
  - 执行时间过长（可能需要10-30分钟）
```

#### 2. 变更历史表增长
```
每日记录：100万条
每月记录：3000万条
每年记录：3.65亿条

问题：
  - 表数据量巨大
  - 查询性能下降
  - 索引维护成本高
```

#### 3. 高并发查询
```
100万DAU × 平均10次/天 = 1000万次查询/天
峰值QPS：1000万 ÷ 86400秒 ≈ 116 QPS（均值）
高峰期3倍：350 QPS

每次查询涉及：
  - 1次 user_membership 查询
  - 可能的 JOIN 操作
```

## 🚀 优化方案

### 方案1：懒加载机制（最推荐）⭐⭐⭐⭐⭐

#### 核心思想
**按需扣费，而非定时扣费**

用户访问时才计算和扣除VIP天数，彻底解决定时任务压力。

#### 实现代码

```java
@Service
public class MembershipService {
    
    @Autowired
    private UserMembershipMapper membershipMapper;
    
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;
    
    /**
     * 获取用户会员信息（含懒加载扣费）
     */
    public MembershipVO getUserMembership(Long userId) {
        // 1. 先从缓存获取
        String cacheKey = "membership:" + userId;
        MembershipVO cached = (MembershipVO) redisTemplate.opsForValue().get(cacheKey);
        if (cached != null) {
            return cached;
        }
        
        // 2. 从数据库查询
        UserMembership membership = membershipMapper.selectByUserId(userId);
        if (membership == null) {
            return createDefaultMembership(userId);
        }
        
        // 3. 懒加载：检查是否需要扣费
        LocalDate today = LocalDate.now();
        LocalDate lastConsumeDate = membership.getLastConsumeDate();
        
        if (lastConsumeDate == null || lastConsumeDate.isBefore(today)) {
            membership = consumeVipDaysLazy(membership, today);
        }
        
        // 4. 构建VO并缓存
        MembershipVO vo = buildVO(membership);
        redisTemplate.opsForValue().set(cacheKey, vo, 1, TimeUnit.HOURS);
        
        return vo;
    }
    
    /**
     * 懒加载扣费
     */
    @Transactional
    private UserMembership consumeVipDaysLazy(UserMembership membership, LocalDate today) {
        LocalDate lastConsumeDate = membership.getLastConsumeDate();
        
        // 计算需要扣除的天数
        int daysToConsume;
        if (lastConsumeDate == null) {
            // 首次消费，只扣1天
            daysToConsume = 1;
        } else {
            // 计算间隔天数
            daysToConsume = (int) ChronoUnit.DAYS.between(lastConsumeDate, today);
        }
        
        if (daysToConsume <= 0) {
            return membership;
        }
        
        // 批量扣除天数（按优先级）
        int remaining = daysToConsume;
        
        // 先扣年度
        if (membership.getYearlyVipDays() > 0) {
            int consume = Math.min(remaining, membership.getYearlyVipDays());
            membership.setYearlyVipDays(membership.getYearlyVipDays() - consume);
            remaining -= consume;
        }
        
        // 再扣季度
        if (remaining > 0 && membership.getQuarterlyVipDays() > 0) {
            int consume = Math.min(remaining, membership.getQuarterlyVipDays());
            membership.setQuarterlyVipDays(membership.getQuarterlyVipDays() - consume);
            remaining -= consume;
        }
        
        // 最后扣月度
        if (remaining > 0 && membership.getMonthlyVipDays() > 0) {
            int consume = Math.min(remaining, membership.getMonthlyVipDays());
            membership.setMonthlyVipDays(membership.getMonthlyVipDays() - consume);
        }
        
        // 更新最后消费日期
        membership.setLastConsumeDate(today);
        membershipMapper.updateById(membership);
        
        // 异步记录变更历史（避免阻塞主流程）
        asyncLogConsume(membership.getUserId(), daysToConsume, membership);
        
        return membership;
    }
    
    /**
     * 异步记录消费历史
     */
    @Async
    private void asyncLogConsume(Long userId, int days, UserMembership membership) {
        MembershipChangeLog log = new MembershipChangeLog();
        log.setUserId(userId);
        log.setChangeType("consume");
        log.setDaysChange(-days);
        log.setMonthlyVipDaysAfter(membership.getMonthlyVipDays());
        log.setQuarterlyVipDaysAfter(membership.getQuarterlyVipDays());
        log.setYearlyVipDaysAfter(membership.getYearlyVipDays());
        log.setRemark("懒加载扣除" + days + "天");
        changeLogMapper.insert(log);
    }
}
```

#### 优势分析

| 对比项 | 定时任务方案 | 懒加载方案 |
|--------|-------------|-----------|
| 数据库压力 | 集中（凌晨高峰） | 分散（全天均匀） |
| 执行时间 | 10-30分钟 | 毫秒级 |
| 锁竞争 | 严重 | 无 |
| 长期未登录用户 | 仍需处理 | 自动跳过 |
| 失败影响 | 影响所有用户 | 仅影响单个用户 |

**性能提升**：
- ✅ 消除定时任务瓶颈
- ✅ 数据库压力从集中变为分散
- ✅ 响应时间从分钟级降到毫秒级
- ✅ 自动处理僵尸用户（长期不登录）

### 方案2：Redis缓存层

#### 架构设计

```
用户请求
    ↓
Redis缓存（热数据）
    ↓ (cache miss)
MySQL数据库（持久化）
```

#### 实现代码

```java
@Service
public class MembershipCacheService {
    
    private static final String CACHE_PREFIX = "membership:";
    private static final long CACHE_TTL = 3600; // 1小时
    
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;
    
    @Autowired
    private UserMembershipMapper membershipMapper;
    
    /**
     * 获取会员信息（缓存优先）
     */
    public MembershipVO getMembership(Long userId) {
        String key = CACHE_PREFIX + userId;
        
        // 1. 尝试从缓存获取
        MembershipVO cached = (MembershipVO) redisTemplate.opsForValue().get(key);
        if (cached != null) {
            return cached;
        }
        
        // 2. 从数据库加载
        UserMembership membership = membershipMapper.selectByUserId(userId);
        MembershipVO vo = buildVO(membership);
        
        // 3. 写入缓存
        redisTemplate.opsForValue().set(key, vo, CACHE_TTL, TimeUnit.SECONDS);
        
        return vo;
    }
    
    /**
     * 购买会员时更新缓存
     */
    @Transactional
    public void purchaseMembership(Long userId, Integer level, Long orderId) {
        // 1. 更新数据库
        // ... 数据库更新逻辑 ...
        
        // 2. 删除缓存（下次查询时重建）
        String key = CACHE_PREFIX + userId;
        redisTemplate.delete(key);
    }
    
    /**
     * 使用优化次数时更新缓存
     */
    public void useOptimize(Long userId) {
        String key = CACHE_PREFIX + userId;
        
        // 先更新数据库
        membershipMapper.decrementOptimizeCount(userId);
        
        // 再删除缓存
        redisTemplate.delete(key);
    }
}
```

#### 缓存策略

```java
/**
 * 分级缓存策略
 */
public class CacheStrategy {
    
    // L1: 本地缓存（Caffeine）- 1分钟
    private LoadingCache<Long, MembershipVO> localCache;
    
    // L2: Redis缓存 - 1小时
    private RedisTemplate<String, Object> redisTemplate;
    
    // L3: MySQL数据库 - 持久化
    private UserMembershipMapper membershipMapper;
    
    public MembershipVO getMembership(Long userId) {
        // L1 → L2 → L3
        MembershipVO vo = localCache.get(userId);
        if (vo == null) {
            vo = getFromRedis(userId);
            if (vo == null) {
                vo = getFromDB(userId);
                cacheToRedis(userId, vo);
            }
            cacheToLocal(userId, vo);
        }
        return vo;
    }
}
```

### 方案3：定时任务优化（如果必须用定时任务）

#### 3.1 分片执行

```java
@Service
public class ShardedVipConsumeTask {
    
    private static final int BATCH_SIZE = 1000;
    private static final int SHARD_COUNT = 100; // 分成100片
    
    /**
     * 每个分片独立执行（分布在不同时间）
     */
    @Scheduled(cron = "0 */1 1 * * ?") // 凌晨1点开始，每分钟一批
    public void consumeVipDaysShard1() {
        consumeShardUsers(0, SHARD_COUNT);
    }
    
    @Scheduled(cron = "0 */1 1 * * ?")
    public void consumeVipDaysShard2() {
        consumeShardUsers(1, SHARD_COUNT);
    }
    
    // ... 更多分片 ...
    
    /**
     * 处理指定分片的用户
     */
    @Transactional
    public void consumeShardUsers(int shardId, int shardCount) {
        int offset = 0;
        
        while (true) {
            // 分页查询（避免一次性加载过多）
            List<UserMembership> batch = membershipMapper.selectShardUsers(
                shardId, shardCount, offset, BATCH_SIZE
            );
            
            if (batch.isEmpty()) {
                break;
            }
            
            // 批量处理
            for (UserMembership membership : batch) {
                consumeVipDays(membership);
            }
            
            offset += BATCH_SIZE;
            
            // 避免长事务，每批提交一次
            TransactionAspectSupport.currentTransactionStatus().flush();
        }
    }
}
```

#### 3.2 使用消息队列

```java
@Service
public class MQVipConsumeTask {
    
    @Autowired
    private RabbitTemplate rabbitTemplate;
    
    /**
     * 生产者：推送任务到消息队列
     */
    @Scheduled(cron = "0 0 1 * * ?")
    public void produceVipConsumeTasks() {
        int offset = 0;
        int batchSize = 100;
        
        while (true) {
            List<Long> userIds = membershipMapper.selectActiveVipUserIds(offset, batchSize);
            if (userIds.isEmpty()) break;
            
            // 批量推送到消息队列
            for (Long userId : userIds) {
                rabbitTemplate.convertAndSend("vip.consume.queue", userId);
            }
            
            offset += batchSize;
        }
    }
    
    /**
     * 消费者：处理VIP扣费
     */
    @RabbitListener(queues = "vip.consume.queue", concurrency = "10-50")
    public void consumeVipDays(Long userId) {
        UserMembership membership = membershipMapper.selectByUserId(userId);
        // 执行扣费逻辑
        consumeVipDays(membership);
    }
}
```
