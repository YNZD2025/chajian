## 值得借鉴的设计

### 1. 发布-订阅模式应用
用于 Token 刷新的并发控制，可应用于其他需要单一操作多消费者等待的场景。

### 2. WeakMap 内存管理
使用 WeakMap 缓存 DOM 样式，当 DOM 元素删除时自动清理，无需手动维护。

### 3. 分阶段 API 调用
识别→优化→生成→填写四个阶段，清晰的职责划分和扩展性强。

### 4. HTML 清理的完整流程
11 步清理流程，确保数据安全和大小优化，可复用于其他场景。

### 5. Mutation Observer 高效使用
只监听相关属性（class、style），配合 WeakSet 避免内存泄漏。

## 实现难点和解决方案

| 难点 | 解决方案 | 关键代码 |
|------|---------|---------|
| 多框架表单兼容性 | 不直接修改 DOM，而是触发事件 | 完整的事件序列触发 |
| 异步表单验证 | 多次轮询 + 超时检查 | 10 次 100ms 检查 = 1s 超时 |
| 日期选择器差异 | 逐级点击（年→月→日） | 查找选项 + 顺序点击 |
| 特殊字段识别 | 统计选项的共性 | 31 省份、56 民族、180+ 国家 |
| 学习数据处理 | 防抖 + 累积 | 5s 检查变化，10s 最多发送一次 |
