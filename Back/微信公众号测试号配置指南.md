# 微信公众号测试号配置指南

## 🎯 为什么使用测试号？

**开发阶段强烈推荐使用测试号**：
- ✅ **免费**：无需认证费用
- ✅ **快速**：5分钟即可开始开发
- ✅ **完整**：功能完全够用
- ✅ **灵活**：随时重置，不影响正式号

## 📋 完整配置步骤

### 步骤1：申请测试号（2分钟）

1. **访问测试号申请页面**
   ```
   https://mp.weixin.qq.com/debug/cgi-bin/sandbox?t=sandbox/login
   ```

2. **微信扫码登录**
   - 用你的个人微信扫描页面上的二维码
   - 确认登录

3. **获取测试号信息**

   登录成功后，页面会显示：

   ```
   测试号信息
   ┌─────────────────────────────────────┐
   │ appID:     wxb07f78f58f3962f2       │
   │ appsecret: baee645bd346b42b9399... │
   └─────────────────────────────────────┘
   ```

   **📝 重要**：复制这两个值到记事本，后面要用！

### 步骤2：配置网页授权回调域名（3分钟）

1. **在测试号页面下滚**，找到这个区域：

   ```
   网页服务
   └─ 网页授权获取用户基本信息
      └─ 授权回调页面域名: [修改]
   ```

2. **点击"修改"按钮**

3. **填写你的 natapp 域名**

   ⚠️ **重要规则**：
   - ✅ 只填写域名，不要 `http://`
   - ✅ 不要加路径
   - ✅ 不要加端口

   ```
   ✅ 正确示例：
   ja7bf743.natappfree.cc

   ❌ 错误示例：
   http://ja7bf743.natappfree.cc
   http://ja7bf743.natappfree.cc/auth/wechat/callback
   ja7bf743.natappfree.cc:8080
   ```

4. **点击"确定"保存**

### 步骤3：获取 natapp 域名（如果还没有）

1. **下载并启动 natapp**
   ```bash
   natapp.exe -authtoken=你的authtoken
   ```

2. **记录公网地址**
   ```
   启动成功后显示：
   Forwarding http://ja7bf743.natappfree.cc -> 127.0.0.1:8080

   复制这个域名: ja7bf743.natappfree.cc
   ```

3. **返回步骤2，填写这个域名**

### 步骤4：配置项目（2分钟）

打开 `yinianzhida/src/main/resources/application.properties`

找到微信配置部分，填写测试号信息：

```properties
# 微信公众号配置（测试号）
wechat.mp.appId=wxb07f78f58f3962f2
wechat.mp.appSecret=baee645bd346b42b9399c6b5e55b0f3c

# 微信回调地址（natapp地址）
wechat.callback.url=http://ja7bf743.natappfree.cc/auth/wechat/callback
```

### 步骤5：添加测试用户（可选）

如果需要其他人帮你测试登录：

1. **在测试号页面找到"测试号二维码"**

   ```
   测试号二维码
   [二维码图片]
   用户列表
   └─ (暂无用户)
   ```

2. **让测试用户扫码关注**
   - 测试用户用微信扫描这个二维码
   - 关注后会出现在"用户列表"

3. **现在该用户也可以扫码登录了**

### 步骤6：启动项目测试

**终端1 - 启动 natapp**
```bash
natapp.exe -authtoken=你的authtoken
# 保持运行
```

**终端2 - 启动后端**
```bash
cd yinianzhida
./mvnw spring-boot:run
```

**终端3 - 启动前端**
```bash
cd qianduanyemianzhanshi
npm run dev
```

**浏览器测试**
```
访问: http://localhost:3000/login
点击生成二维码
用微信扫码
✅ 登录成功！
```

## ❓ 常见问题

### Q1: 找不到"网页授权获取用户基本信息"在哪里？

**A**: 在测试号页面向下滚动，会看到多个区域：
1. 测试号信息 ⬅️ 在顶部
2. 接口配置信息
3. JS接口安全域名
4. **网页服务** ⬅️ 在这里！
5. 体验号二维码

### Q2: 提示"redirect_uri 参数错误"怎么办？

**检查清单**：
- [ ] 测试号页面是否配置了回调域名？
- [ ] 配置的域名是否和 natapp 地址一致？
- [ ] 域名是否去掉了 `http://`？
- [ ] natapp 是否正在运行？
- [ ] `application.properties` 中的回调地址是否正确？

**正确配置示例**：
```
测试号页面配置: ja7bf743.natappfree.cc
application.properties: http://ja7bf743.natappfree.cc/auth/wechat/callback
```

### Q3: 扫码后显示"该公众号暂时无法提供服务"？

**可能原因**：
1. natapp 没有启动
2. 后端没有启动
3. 回调地址配置错误

**排查步骤**：
```bash
# 1. 检查 natapp 是否运行
# 看终端是否有 "Forwarding http://xxx -> 127.0.0.1:8080"

# 2. 检查后端是否运行
curl http://localhost:8080/test/hello

# 3. 检查 natapp 转发是否正常
curl http://你的natapp地址/test/hello

# 4. 查看后端日志
# 看是否有请求到达
```

### Q4: 每次 natapp 重启地址都变怎么办？

**方案1**：购买固定域名隧道（推荐）
```
natapp 官网 → 购买隧道 → VIP_1型（9元/月）
域名固定，配置一次永久有效
```

**方案2**：使用环境变量
```bash
# 每次启动时设置
set WECHAT_CALLBACK_URL=http://新的natapp地址/auth/wechat/callback

# 重启后端即可，不用改配置文件
```

**方案3**：写个脚本
```bash
# update-config.bat
@echo off
echo 当前natapp地址是什么？（不要http://）
set /p NATAPP=
echo wechat.callback.url=http://%NATAPP%/auth/wechat/callback
echo.
echo 复制上面这行，替换 application.properties 中对应的配置
pause
```

### Q6: 上线时如何从测试号切换到正式号？

**步骤**：
1. 申请并认证正式公众号
2. 获取正式号的 AppID 和 AppSecret
3. 修改 `application-prod.properties`：
   ```properties
   wechat.mp.appId=正式号AppID
   wechat.mp.appSecret=正式号AppSecret
   wechat.callback.url=https://api.applymind.com/auth/wechat/callback
   ```
4. 在正式号后台配置回调域名
5. 部署到生产服务器

**注意**：正式号配置流程类似，但需要下载验证文件
