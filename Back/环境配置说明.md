# 环境配置说明

## 📁 配置文件结构

```
src/main/resources/
├── application.yml           # 主配置文件（公共配置）
├── application-dev.yml       # 开发环境配置
├── application-test.yml      # 测试环境配置
└── application-prod.yml      # 生产环境配置
```

---

## 🔧 各环境配置对比

| 配置项 | 开发环境 (dev) | 测试环境 (test) | 生产环境 (prod) |
|--------|---------------|----------------|----------------|
| **端口** | 8080 | 8081 | 8080（可配置） |
| **数据库** | localhost:3306/applymind | localhost:3306/applymind_test | 生产服务器（环境变量） |
| **数据库连接池** | 最大10个连接 | 最大20个连接 | 最大50个连接 |
| **日志级别** | DEBUG | INFO/DEBUG | WARN/INFO |
| **SQL日志** | ✅ 打印 | ✅ 打印 | ❌ 不打印 |
| **日志保留** | 30天 | 60天 | 90天 |
| **文件上传限制** | 10MB | 10MB | 20MB |
| **AI超时时间** | 30s/60s | 45s/90s | 60s/120s |
| **微信回调** | 内网穿透URL | 测试域名 | 正式域名 |

## 🚀 启动方式

### 1. 开发环境（默认）

```bash
# 方式1：直接运行（默认使用dev环境）
java -jar yinianzhida.jar

# 方式2：显式指定dev环境
java -jar yinianzhida.jar --spring.profiles.active=dev

# 方式3：IDE中配置
# IDEA: Run -> Edit Configurations -> Active profiles: dev
mvn spring-boot:run
```

### 2. 测试环境

```bash
# 方式1：启动参数
java -jar yinianzhida.jar --spring.profiles.active=test

# 方式2：环境变量
export SPRING_PROFILES_ACTIVE=test
java -jar yinianzhida.jar

# 方式3：Maven
mvn spring-boot:run -Dspring-boot.run.profiles=test
```

### 3. 生产环境

```bash
# 方式1：启动参数
java -jar yinianzhida.jar --spring.profiles.active=prod

# 方式2：环境变量
export SPRING_PROFILES_ACTIVE=prod
java -jar yinianzhida.jar

# 方式3：systemd服务
# 在 /etc/systemd/system/yinianzhida.service 中配置
Environment="SPRING_PROFILES_ACTIVE=prod"
```

## 🔐 环境变量配置

### 开发环境（可选）

开发环境的环境变量都有默认值，可以不配置。

### 测试环境（推荐配置）

```bash
# 数据库配置
export DB_HOST=localhost
export DB_PORT=3306
export DB_USERNAME=root
export DB_PASSWORD=your_password

# 微信配置
export WECHAT_APP_ID=your_test_appid
export WECHAT_APP_SECRET=your_test_appsecret
export WECHAT_CALLBACK_URL=http://test.your-domain.com/auth/wechat/callback

# JWT配置
export JWT_SECRET=your_test_jwt_secret

# AI配置
export OPENAI_API_KEY=your_api_key
```

### 生产环境（必须配置）

```bash
# 数据库配置（必须）
export DB_HOST=prod-db-server
export DB_PORT=3306
export DB_NAME=applymind
export DB_USERNAME=applymind_user
export DB_PASSWORD=strong_password_here

# 微信配置（必须）
export WECHAT_APP_ID=your_prod_appid
export WECHAT_APP_SECRET=your_prod_appsecret
export WECHAT_TOKEN=your_prod_token
export WECHAT_CALLBACK_URL=https://your-domain.com/auth/wechat/callback

# JWT配置（必须）
export JWT_SECRET=very_long_and_secure_secret_key_for_production

# AI配置（必须）
export OPENAI_API_KEY=your_production_api_key
export OPENAI_BASE_URL=https://g.thank.xx.kg
export OPENAI_MODEL=claude-sonnet-4-20250514

# 应用配置（必须）
export APP_BASE_URL=https://your-domain.com
export SERVER_PORT=8080

# Spring配置
export SPRING_PROFILES_ACTIVE=prod
```

## 📝 配置文件使用示例

### Docker 部署

**docker-compose.yml**

```yaml
version: '3.8'

services:
  # 开发环境
  yinianzhida-dev:
    image: yinianzhida:latest
    ports:
      - "8080:8080"
    environment:
      - SPRING_PROFILES_ACTIVE=dev
    volumes:
      - ./logs:/app/logs

  # 测试环境
  yinianzhida-test:
    image: yinianzhida:latest
    ports:
      - "8081:8081"
    environment:
      - SPRING_PROFILES_ACTIVE=test
      - DB_HOST=mysql-test
      - DB_PASSWORD=${DB_PASSWORD}
      - WECHAT_APP_ID=${WECHAT_TEST_APP_ID}
      - WECHAT_APP_SECRET=${WECHAT_TEST_APP_SECRET}
    depends_on:
      - mysql-test

  # 生产环境
  yinianzhida-prod:
    image: yinianzhida:latest
    ports:
      - "8080:8080"
    environment:
      - SPRING_PROFILES_ACTIVE=prod
      - DB_HOST=${PROD_DB_HOST}
      - DB_USERNAME=${PROD_DB_USER}
      - DB_PASSWORD=${PROD_DB_PASSWORD}
      - WECHAT_APP_ID=${PROD_WECHAT_APP_ID}
      - WECHAT_APP_SECRET=${PROD_WECHAT_APP_SECRET}
      - JWT_SECRET=${PROD_JWT_SECRET}
      - OPENAI_API_KEY=${PROD_OPENAI_KEY}
    depends_on:
      - mysql-prod
    restart: always
```

### Kubernetes 部署

**k8s-configmap.yaml**

```yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: yinianzhida-config-prod

  SPRING_PROFILES_ACTIVE: "prod"
  DB_HOST: "mysql-service"
  DB_PORT: "3306"
  DB_NAME: "applymind"

  name: yinianzhida-secret-prod
type: Opaque
stringData:
  DB_PASSWORD: "your-db-password"
  WECHAT_APP_SECRET: "your-wechat-secret"
  JWT_SECRET: "your-jwt-secret"
  OPENAI_API_KEY: "your-openai-key"
```

### systemd 服务配置

**/etc/systemd/system/yinianzhida.service**

```ini
[Unit]
Description=YinianZhida Application
After=network.target

[Service]
Type=simple
User=appuser
WorkingDirectory=/opt/yinianzhida
ExecStart=/usr/bin/java -jar /opt/yinianzhida/yinianzhida.jar

# 环境配置
Environment="SPRING_PROFILES_ACTIVE=prod"
Environment="DB_HOST=localhost"
Environment="DB_PASSWORD=your_password"
EnvironmentFile=/opt/yinianzhida/config/app.env

# JVM参数
Environment="JAVA_OPTS=-Xms512m -Xmx2048m -XX:+UseG1GC"

# 日志
StandardOutput=journal
StandardError=journal
SyslogIdentifier=yinianzhida

# 重启策略
Restart=on-failure
RestartSec=10

[Install]
WantedBy=multi-user.target
```

## ⚙️ 配置优先级

Spring Boot 配置加载优先级（从高到低）：

1. **命令行参数** 
   ```bash
   --spring.datasource.password=123456
   ```

2. **环境变量**
   ```bash
   export DB_PASSWORD=123456
   ```

3. **application-{profile}.yml**
   ```yaml
   spring:
     datasource:
       password: 123456
   ```

4. **application.yml**
   ```yaml
   spring:
     datasource:
       password: ${DB_PASSWORD:default_password}
   ```

## 📚 最佳实践

### 1. 敏感信息处理

❌ **不要做**：
```yaml
# 不要在配置文件中硬编码密码
spring:
  datasource:
    password: 123456
```

✅ **推荐做法**：
```yaml
# 使用环境变量
spring:
  datasource:
    password: ${DB_PASSWORD}
```

### 2. 配置文件管理

- ✅ `application.yml` - 提交到 Git
- ✅ `application-dev.yml` - 提交到 Git（使用默认测试值）
- ✅ `application-test.yml` - 提交到 Git（使用占位符）
- ✅ `application-prod.yml` - 提交到 Git（使用占位符）
- ❌ `.env` 文件 - 不要提交到 Git（添加到 .gitignore）

### 3. 日志配置建议

- **开发环境**：DEBUG 级别，打印SQL
- **测试环境**：INFO 级别，打印重要操作
- **生产环境**：WARN/INFO 级别，不打印SQL

### 4. 数据库连接池

根据实际负载调整：

```yaml
# 低负载（开发/测试）
hikari:
  maximum-pool-size: 10

# 中负载（小型生产）
hikari:
  maximum-pool-size: 30

# 高负载（大型生产）
hikari:
  maximum-pool-size: 50-100
```

## 🔧 常见问题

### Q1: 如何查看当前使用的环境？

**A**: 启动日志会显示：
```
The following 1 profile is active: "dev"
```

### Q2: 配置没有生效怎么办？

**A**: 检查优先级：
1. 确认环境变量是否正确设置
2. 确认配置文件命名是否正确（application-{profile}.yml）
3. 确认 `spring.profiles.active` 是否设置正确

### Q3: 如何在本地测试生产配置？

**A**: 使用环境变量：
```bash
export SPRING_PROFILES_ACTIVE=prod
export DB_HOST=localhost
export DB_PASSWORD=123456
# ... 其他必需的环境变量
java -jar yinianzhida.jar
```

### Q4: 如何动态切换环境？

**A**: 重启应用并指定不同的 profile：
```bash
# 从dev切换到prod
pkill -f yinianzhida.jar
java -jar yinianzhida.jar --spring.profiles.active=prod
```
